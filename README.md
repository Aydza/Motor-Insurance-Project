# Predictive Modeling for Motor Insurance Claim Frequency

[cite_start]This project focuses on developing, tuning, and comparing multiple statistical and machine learning approaches to model the frequency of car insurance claims[cite: 2, 6]. [cite_start]Utilizing a portfolio dataset of car insurance policies, the objective is to accurately estimate claims frequency ($\lambda(x)$) by leveraging traditional generalized linear models (GLMs), tree-based methods, and ensemble boosting techniques[cite: 3, 9, 12, 14, 17].

---

## Project Overview

[cite_start]In general insurance, accurately predicting claim frequency is critical for risk assessment, policy pricing, and maintaining underwriting profitability[cite: 2, 6]. [cite_start]This research project implements a rigorous workflow to model claim counts ($N_i$) assuming a Poisson distribution offset by policy exposure ($v_i$)[cite: 3]:

$$N_{i}\sim Poisson(v_{i}\lambda(x_{i}))$$

[cite_start]The predictive feature vector $x_i$ includes a mix of continuous and categorical risk factors[cite: 3, 4, 5]:
* [cite_start]**`weight` ($x_1$):** Car weight [cite: 4]
* **`distance` ($x_2$):** Annually driven distance [cite: 4]
* **`age` ($x_3$):** Age of the driver [cite: 5]
* **`carage` ($x_4$):** Age of the car [cite: 5]
* **`gender` ($x_5$):** Gender of the driver [cite: 5]

---

## Research Objectives & Methodologies

The project is structured into distinct phases to systematically evaluate different algorithmic complexities:

### 1. Exploratory Data Analysis (EDA)
* Analyze summary statistics and distributions (histograms) for all risk factors.
* [cite_start]Evaluate pairwise correlations to detect potential multicollinearity or non-linear relationships.

### 2. Parametric Modeling: Generalized Linear Models (GLM)
* [cite_start]Estimate $\ln \lambda(x)$ using a Poisson GLM featuring linear components, quadratic terms for continuous variables ($x_1$ to $x_4$), and specified two-way interaction terms ($x_1x_2, x_1x_3, x_1x_4, x_2x_3, x_2x_4, x_3x_4$)[cite: 9].
* Perform systematic variable selection to identify what terms should be kept and what terms can be dropped[cite: 10].
* [cite_start]Establish a baseline prediction and visualize the isolated effect of driver age ($x_3$) on frequency via partial dependency plotting.

### 3. Non-Parametric Modeling: Poisson Regression Trees
* Train a Poisson regression tree to automatically capture non-linearities and high-order feature interactions[cite: 12].
* [cite_start]Determine the optimal tree size using cost-complexity pruning to prevent overfitting[cite: 12].
* [cite_start]Plot the final optimal architecture and benchmark its predictions against the GLM baseline[cite: 13].

### 4. Ensemble Methods: Gradient Boosting Machine (GBM)
* **From Scratch:** Implement a Poisson boosting tree method starting from a null base model ($\lambda(x) = 1$) before boosting steps[cite: 14]. Optimize hyperparameters including the number of boosting iterations, tree depth, and shrinkage parameter[cite: 15].
* [cite_start]**Model Residual Boosting:** Implement a hybrid ensemble architecture utilizing the optimized parametric GLM from Section B as the base model, letting the gradient boosted trees model the remaining residuals[cite: 17]. [cite_start]Optimize the hyperparameters accordingly[cite: 18].

### 5. Validation and Model Selection
* Execute a **10-fold cross-validation** framework to evaluate out-of-sample performance across all four models (GLM, Pruned Tree, Vanilla GBM, and Hybrid GBM).
* [cite_start]Compare cross-validation errors to objectively select the champion model for deployment.

### 6. High-Risk Classification (Extension Analysis)
* [cite_start]Engineer a binary categorical target, `High` ($Yes$ if claims count $N \ge 2$, $No$ otherwise), to identify high-frequency systematic risks[cite: 21].
* Fit an equivalent logistic regression model with linear, quadratic, and interaction terms, assuming a baseline exposure of 1 for simplicity[cite: 22, 23].
* [cite_start]Perform variable selection to find the best model and compare its estimated probability of a high-risk policy against the implied probabilities generated by the primary Poisson frequency models[cite: 23, 24, 25, 26].
